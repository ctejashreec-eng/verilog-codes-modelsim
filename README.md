# Verilog Digital Logic Designs (ModelSim)

This repository contains Verilog HDL design modules and their corresponding testbenches created for simulation in **ModelSim**. The designs cover fundamental combinational and sequential digital logic components.

---

## 📁 Repository Structure

| Module File | Testbench File | Description |
| :--- | :--- | :--- |
| `full_add.v` | `full_add_tb.v` | **1-Bit Full Adder:** Computes the binary sum of two bits (`A`, `B`) and an input carry (`Cin`), generating a `Sum` and `Cout`. |
| `d_flip_flop.v` | `D_flip_flop_tb.v` | **D Flip-Flop:** Sequential memory element that captures the data input (`D`) on the clock edge and outputs it to `Q`. |
